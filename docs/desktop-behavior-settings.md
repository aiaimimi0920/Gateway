# 模型显示与桌面行为设置

## 模型名带供应商

这是当前浏览器配置文件中的显示偏好，沿用 `gateway-ui-display` 存储；不改写路由、API 模型 ID、统计键或调用参数。

- 关闭：账号模型列表和模型池卡片只显示模型名称。
- 自定义名称不带供应商：配置中的全局 `aliases`、供应商 `model_map` / `model_map_targets` 键视为自定义名称，保持原名；其他名称附带供应商。
- 开启：附带实际供应商名称。模型池有多个供应商时显示去重后的供应商列表，不把模型开发者猜成实际服务商。
- API 原始响应、Model ID 字段、路由编辑输入保持原始标识符；悬停提示保留原始 ID。

## 桌面客户端专属

浏览器不调用原生 IPC；三个控件在网页中保持禁用并标注“仅桌面客户端可用”。桌面设置仍由可信本地子视图调用原生命令，远程控制台不直接获得系统操作权限。

### 防止休眠（Windows）

- 关闭：不持有电源请求，遵循系统电源设置。
- 开启：保持系统唤醒，允许屏幕按系统设置关闭。
- 屏幕也常亮：同时保持系统和屏幕唤醒。

独立线程拥有 `SetThreadExecutionState` 请求，更新和释放在同一线程执行。最小化到托盘仍属于应用运行期间；退出时清除请求并结束线程，进程异常退出后 Windows 也会清理线程请求。不禁止手动休眠、锁屏或关机，也不修改系统电源计划。

偏好保存在当前数据根的 `desktop-settings.json`，新增 `sleepMode` 缺省为 `off`；旧配置可直接读取。启动时重新应用，保存失败恢复之前的运行模式。

### 关闭窗口时

沿用 `closeBehavior`：`exit` 退出程序；`tray` 隐藏至托盘。没有托盘时拒绝保存托盘模式。托盘菜单的“退出”仍直接退出，不再次隐藏。标题栏最小化按钮保持原来的最小化行为。

### 开机启动（Windows）

沿用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 专用值 `NeuroGatewayDesktop`，不要求管理员权限，不修改其他应用启动项。开启表示用户登录 Windows 时启动。

启动项包含当前程序路径及数据根，避免隔离测试实例重启后误连默认数据。旧的仅含 `--gateway-autostart` 的记录仍可识别。关闭只删除此专用启动项。现有程序被移动后，需要重新关闭并开启此选项以注册新路径。

本轮没有通过修改真实注册表来测试启动项，也没有进行 Windows 注销/重启验收；自动测试覆盖原生配置读写、请求模式与释放、启动参数、前端保存及显示更新。
