# NVIDIA 真实目录、账号模型池与调用证据分离

## 本轮范围

实现 NVIDIA 专用模板的目录读取、账号模型池和精确模型路由同步；
区分目录发现与真实成功调用。不执行逐模型生成测试，不改当前运行的 4200 实例。

## 改动

- 管理端新增 `POST /v1/internal/gateway/console/nvidia-model-catalog`。
  上游只请求固定官方 `GET https://integrate.api.nvidia.com/v1/models`，不调用生成接口。
  管理认证、Secret Grant、网络结束后的授权复核和既有双槽并发限制均保留。
  禁止任意目的地址、重定向、凭据混合覆盖；请求总时限 30 秒、响应上限 2 MiB、模型上限 2048。
- 新账号保存前读取目录；已有账号编辑面板提供“刷新模型目录”。
  revision、会话、取消和草稿变更检查后才接收结果；失败不覆盖 last-good 文档。
- 账号新增可选 `model_catalog`，只存来源、时间、模型 ID；旧配置读取兼容，无存储版本升级。
  生产前端合并器更新账号模型池、服务商并集和路由，保留目录外手工声明、其他账号、
  其他服务商、优先级及禁用策略。重复同步幂等，包括旧默认模型也在新目录中的情况。
- 模型列表改称“模型池”；显示“目录已发现”“有成功记录”“尚无成功”“未验证”。
  成功证据取精确服务商/账号归属的保留审计，不写入虚假的 `verified_models` 或模型健康状态。
