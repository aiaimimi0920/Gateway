# 测试配置交互精简

## 用户要求

- 默认只显示操作、数据和必要状态，不添加常驻解释型 UI。
- 凭据池入口显示“全池 / 子池 / 账户”三个单选项。
- 全池作用于当前凭据卡牌；子池展开二级多选；账户选择一个独立账户。
- 各层策略同时存在，保存当前对象不得擦除其他层或未选对象。
- 单账户卡牌入口锁定该账户，不允许切换范围或账户。

## 实现边界

复用现有策略 DTO、继承规则、配置自动保存和敏感操作授权。
仅扩展前端范围选择与原子批量写入；多对象手动调用串行、可取消且有总量限制。
不增加后端协议、数据库版本、第三方依赖或真实账户测试。

## 验收

1. 三项单选、子池多选、账户锁定及模式切换状态保留。
2. 同时保存全池、不同子池和账户策略，独立覆盖与秘密不变。
3. 批量保存一次提交；无效对象不得产生部分写入。
4. 手动调用只触及选定对象，关闭或授权失败不继续下一项。
5. 删除测试配置与结果区的常驻说明，保留具体数据、错误和权限控制。
6. 类型检查、聚焦测试、checker、真实宽窄屏与唯一 Windows 包。

证据目录：`linshi/gateway-test-scope-ui-20261005`。不提交、推送或覆盖旧包。
