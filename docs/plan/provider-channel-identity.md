## 1. 身份规则

`templateId / providerId / preset / adapter` 分别是新建入口、用户实例、协议默认值和执行 owner；不从可改 ID 的后缀推断材料身份。
认证方式、产品受众和额度维度分别记录。相同邮箱、模型、Bearer header 或协议不能证明相同权益。
`shared` 必须注明共同 account/project/region/model/client 等条件；`independent` 只覆盖来源明确比较的产品；其余 `unknown`。
这些状态不自动合并凭据池、共享秘密、开启路由回退或修改已有实例。
