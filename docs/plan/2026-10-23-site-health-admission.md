# 站点健康准入与真实调用模型熔断

用户已于 2026-10-23 授权开发。保留现有未提交修改，不部署、不访问真实模型。

## 验收边界

- 每服务商支持多检测方案；每方案绑定一个或多个本地凭证组，共享方案不重复探测。
- 默认自动识别有限健康接口；手动选择时不回退其他适配器。仅正确 schema 是证据。
- 单独监控认证，不借用业务凭据，不向无关探测模板发送密钥，不在普通配置回显秘密。
- 有效模型可用率低于阈值时在候选选择/排序之前排除；健康恢复只解除自身限制。
- 明确区分本地凭证组与远端监控分类；无分类数据不能冒充已分组检测。
- 真实上游短窗连续失败触发模型硬熔断；默认 60 秒内连续 3 次，2/8/32/60 分钟退避。
- 冷却到期单请求试放，避免并发惊群；失败立即升级，调用取消不污染健康。
- 人工禁用、监控限制、调用熔断各自保留原因，互不解除；无候选不回捞坏目标。

## 实现顺序

1. 纯状态机及故障分类测试；实际 send-start 与流完成生命周期接线。
2. 分组检测配置、手动适配器、独立监控凭据与安全传输；旧配置可读。
3. 前置候选过滤（含池内挑选、多目标映射、access catalog）和模型列表一致性。
4. 管理 UI、定向离线/loopback 验证、类型检查、formatter、行数 ratchet 与文档。

站点接口的具体兼容声明需联网核实官方源码/文档。未核实能力不猜测、不伪造成功率。
临时测试和构建证据放 linshi，不改正在运行的实例和数据。日常构建使用 devtest。
