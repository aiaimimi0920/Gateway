# IQ 测试看板：本轮范围

核心：测试指数、供应商实际额度证据、单位指数额度成本、完成用时。
沿用既有命名计划、手动/自动执行、结果存储和认证，不建立第二套执行器。

## 指标约定

- IQ 是选定题集的 0–100 难度加权测试指数，不是人类 IQ，也不复刻未核实网站算法。
- 同一原始模型、供应商、账户和同一题集分别展示，不能混合不同题目和额度单位排名。
- 用时是该模型各题完整调用耗时之和，包含调用内部开销，不包含额度查询和题间调度。
- 额度只读供应商真实账户余额/用量窗口；不以 tokens、调用数或估算价格代替。
  前后差额仅是账户观测值，外部并发、供应商结算延迟和精度可能影响归因；
  不宣称它是请求级扣费。比值需明确同口径、正分母和完整证据，否则显示不可计算。
- 旧结果保持可读，缺失测量字段不补造。失败、缺题、未评分与真实零值分别处理。

## 完成步骤

1. 添加有界、只读的额度快照及模型用时/题集身份，使用可选结果字段保持旧数据兼容。
2. 结果页改名 IQ，按模型证据卡展示核心参数、单位和测量限制。
3. 增加原创确定性题库，不改写已有计划；现有计划可显式补充题目，不自动增加付费调用。
4. 聚焦测试、类型/编译检查、行数门禁、隔离真实 UI 检查及新手测包。

## 额度查询安全边界

- 复用凭据前校验余额地址与模型服务的 scheme、host、port 完全同源。
- 不接受跨来源地址、URL 内嵌认证、片段及空路径；额度请求不跟随重定向。
- 查询总超时 2 秒、响应体上限 64 KiB；不可读取时只标为不可用，不影响模型测试。
- 受控回归只使用本地合成凭据；跨来源拒绝、无变化、补充、单位不一致、
  不明确的 token 数据、超时和超大响应与正常扣减分别验证。
