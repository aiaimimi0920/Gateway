# 测试计划列表与模型结果汇总

## 本轮目标

凭据池测试入口先显示计划列表；左上角为凭据池名称及“测试 / 结果”，右上角“添加”。
计划支持命名、编辑、确认删除、展开最近结果。添加和编辑复用已有配置表单。
结果页按模型汇总最近已完成轮次的连通度、测试集智能度、调用错误率和答案错误率。

## 数据和执行边界

- 每个 provider 新增可选 `test_plans`，最多 32 个；稳定 ID 不从名称生成。
- 每项保存名称、同类型范围集合及完整策略。全池和账户单选，子池支持多选。
- 命名计划独立执行自己的策略，不受旧三级策略覆盖；旧配置和三级 API 保持兼容。
- 自动和手动共用执行器、revision、128 调用 / 300 秒准入预算及 60 秒单调用超时。
- 结果和到期槽增加计划维度；无计划 ID 时保留旧键，不升级数据库或改写凭据。
- 读取仍要求管理认证和精确 Secret Grant，过滤当前 provider / 范围后有界读取。
- 删除仅更新配置，停止后续准入；已在途调用不可撤回，过期结果仍按原 TTL 清理。
- 汇总仅使用最新保存结果，不宣称全历史统计或通用 IQ。unsupported / not-run
  不加入调用错误率分母；无标准答案不计答案评分。

## 验证和停止条件

聚焦验证同范围多计划、身份/范围拒绝、旧数据兼容、独立调度槽、结果归属、
列表导航、编辑保存/返回、确认删除、结果展开、模型汇总分母、焦点和窄屏。
执行 formatter、类型检查、Rust 编译/聚焦契约、行数 ratchet 和 diff check。
按官方发布链 fresh 构建唯一 Windows 候选，在 loopback 合成账户上验证完整路径。
不调用真实供应商、不提交推送、不部署；保留当前全部 dirty edits 和旧发布包。

## 当前界面调整验收范围（2026-10-06）

- 计划列表采用七列单行表格：名字、测试范围、测试集、自动测试间隔、手动测试、编辑、删除。
- 结果由页面自动读取，每轮完成后间隔 5 秒；展开计划独立读取，编辑和执行期间暂停，不保留手动刷新按钮。
- 编辑器只配置并保存计划；移除自动/手动页签、测试账户勾选区及右侧结果。执行按保存范围选取启用账户。
- 首次登录后自动使用当前管理凭据取得和续期短时 Secret Grant，不再要求重复输入密码。后台管理认证仍保留。
- Grant 仅存内存；续期失败仍独立到期清理，串行且有界重试，换身份、退出与卸载使旧回复失效。
- 完成匹配测试、类型检查、行数门禁和唯一隔离 Windows 包；不使用真实账户或停止现有实例。
