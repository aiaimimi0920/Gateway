# Codex 可选通道与独立站点健康

## 本轮授权与边界

用户明确要求：复用 Codex 凭据，以开关选择 Basispoints；增加独立于账号测试的
站点健康信息，自动尝试已知接口模板，供提示和可配置路由限制使用。
不修改运行中的 CPA、不自动上线、不调用真实模型验证质量，不将换通道等同于更高智力。

## 验收合同

- 账号可选择继承服务商设置、原生通道或 Basispoints；旧配置默认原生。
- 凭据 ID、原始 OAuth 材料与刷新 owner 保持不变；不生成第二份凭据。
- Basispoints 请求、工具往返、终态证明使用独立 Rust owner，无 Go 插件 ABI。
  不支持的内容明确拒绝，不能静默删除约束或将未验证工具交给客户端执行。
- 站点健康与账号探测、配额、计费、凭据 breaker 分开；配置沿用 route document。
- 新建自定义站点默认开启独立健康识别，也可主动关闭；已有站点不自动修改。
  自动以 GET 尝试有限的已知健康端点，embed 模板额外以 POST 读取批量状态，记录所有识别结果。
  不尝试付费推理，不复用账号密钥，不做任意 URL/路径扫描。
- 限制源站、DNS 地址、重定向、并发、总耗时、响应大小与缓存；配置变化使旧结果失效。
- advisory 不拒绝请求；restrict 按显式阈值限制有有效证据的对应模型；未知/过期
  按独立策略处理，默认放行，不清除本地账号错误历史。
- UI 提供实际开关、检测结果和策略，不要求用户手工选择模板。
- 聚焦反例、真实 loopback HTTP、受影响编译/类型检查、格式与有效行数门禁。
