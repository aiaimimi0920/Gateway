# 桌面端关于与更新

“设置 / 关于”复用 React 设置行与 Tauri 本地命令，不更新远程服务器。浏览器版可查询公开发布信息与打开项目链接，不能访问本机配置目录或执行安装。

## 发布契约与默认行为

- 官方仓库：`https://github.com/aiaimimi0920/Gateway`。
- 读取 GitHub Releases，匹配 `Vx.y.z` 的 Windows x64 桌面正式 ZIP 及同名 `.sha256`。稳定渠道排除 prerelease；每个版本渠道包含符合版本格式的 prerelease。
- 当前正式版本读取可执行文件旁的 `manifest.json`。开发版和手测包不自动安装正式包。
- 自动检查、自动下载、自动重启默认关闭；检查间隔可选 1、6、24 小时。
- 自定义 HTTPS 镜像只用于 ZIP 下载；SHA256 始终取自官方仓库。SHA256 是完整性校验，不是数字签名。
- 公开查询不发送 Gateway 管理凭据；网络错误、限流与没有版本分别反馈。

## 本机安装与数据边界

- 原生命令只允许可信本地 main / gateway-local-settings 页面，远端 console 没有更新权限。
- 下载、解压和校验位于选定数据根下的独立 updates 子目录；不覆盖旧包、不迁移或清空数据库。
- 整包 SHA256、路径穿越、重复路径、展开大小、正式 manifest 与文件校验清单均校验通过后，才允许更新。
- 有托管后端时先检查活动请求并优雅排空，不强杀；外部本机和远程后端不在停止范围内。
- 独立 helper 在排空前启动，但只有本次 armed 标记写入后才允许切换。旧桌面退出后启动新包，以唯一 nonce 和 PID 绑定回执。
- 托管本机连接成功后才确认启动；连接远端时只确认本地桌面启动，不以远端在线为更新条件。
- 启动失败尝试恢复旧桌面；若新进程尚未退出，不并行开启另一后端。结果写入 `updates/last-update-result.json`，失败在关于页反馈。
- 活跃版本指针只在确认新进程启动后写入。旧快捷方式读取指针；指针不可用时继续原版本并输出错误。

## 验证范围

定向测试覆盖前端设置保存与安装确认、原生渠道校验与本地面板权限、合成包校验、模拟启动失败回退。测试不执行真实更新、不重启 4200/4400、不使用真实账号数据。

真实正式 ZIP 下载、原生窗口与受管后端实际升级、进程退出和恢复仍需在正式发行候选包的隔离环境验收；网页预览和模拟测试不能替代这一步。
