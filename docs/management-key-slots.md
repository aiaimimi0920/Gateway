# 两行管理密钥

设置页固定显示“管理密钥一”和“管理密钥二”，每行提供密码输入及启禁开关。
输入 Enter 或离开输入框保存；Escape 丢弃未保存输入。禁用不删除密钥。
空的第二行默认禁用，必须填写密钥后才能启用。

后台 `management-keys` 增加 `setSlot` 操作（slot 为 0/1、enabled、可选 token），
仍经过管理鉴权与持久化写锁。已有 v2 key ring 增加 enabled 字段，旧记录缺省为 true；
保留原哈希、密钥标识及加密展示材料，不改存储版本。超过两把的历史 key ring
不会截断或静默禁用；界面拒绝修改并提示先整理历史记录。

没有已启用的密钥时，bootstrap 返回与当前 revision 绑定的公开 passwordlessToken。
前端用该标记完成正常 session 验证和 secret grant 流程，无需用户输入密码。
它不是服务间密钥，不能用于 AI API 的可信转发身份；启用任意密钥或更新 revision
会使旧标记失效。空文件、坏文件、从未配置管理员均不视为免密。

Console 保留原有远程访问限制。通用管理路由用请求作用域传递真实 ConnectInfo，
免密鉴权缺少可信 peer 时拒绝；不相信调用方传入的客户端 IP 请求头。
该作用域不得用于新建后台任务，后台任务必须显式传递经过验证的上下文。

此模式意味着任何已被网关访问策略允许访问控制台的人均可管理网关。
启用远程访问时亦然；启禁操作不自动改变监听地址、远程开关或防火墙。
旧后端未声明 slotsSupported 时，网页只显示现有两行且禁用修改，不模拟保存成功。
