Gateway 图标提案 · 第 1 轮

三组方向，每组三个变体。全部按 24×24 网格绘制，只用两种品牌色（绿 #22c55e 主 / 荧光黄 #d9ff38 次），保证 16px 下不糊。看中哪一个，直接回复编号（例如 A2）；也可以说“A 的外框 + C 的内芯”这类组合意见，我出第 2 轮。

Set A

门 + 链：GATE LINK

外框是“门/关口”，中间是一节链环穿过去 —— 直白表达“流量经由网关被串接转发”。链环是最短路径表达“链接”的符号。

Set B

节点分流：NEURAL ROUTER

一进多出的节点图：左侧单入口、中心枢纽、右侧多出口。节点图本身就是“智能/神经网络”的通用符号，分叉表达“智能选路”。

Set C

括号 + 脉冲：SIGNAL ARCH

两个方括号构成通道，中间是脉冲/火花。偏“开发者工具”气质，和 Neuro 终端风的等宽排版最搭，16px 下最干净。

结论：C3（方括号 + 信号波）已在第 1 轮获批，成为正式图标。 已同步替换：左侧栏商标（GatewayMark() in apps/desktop/src/features/shell/AppShell.tsx）、 favicon（apps/desktop/public/favicon.svg）、以及 Tauri 打包图标 （src-tauri/icons/icon.png 512×512 / icon.ico 16-256 多尺寸， 由 apps/desktop/scripts/render-brand-icons.mjs 从 favicon 光栅化生成）。 本页保留作为设计记录。
