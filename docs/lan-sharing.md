# 局域网共享

该设置属于当前连接的网关后端，不是浏览器或桌面客户端的本地偏好。
缺少历史配置时默认开启；保存后立即作用于后续入站请求，无需重启。
关闭时仅允许后端本机访问，其他设备收到 403 / `gateway_lan_sharing_disabled`。
覆盖模型接口、管理接口与网页；不强制中断已开始的流式响应或已升级的连接。

来源使用真实 TCP `ConnectInfo`，不信任 X-Forwarded-For、X-Gateway-Client-IP 等请求头。
loopback（含 IPv4-mapped IPv6）直接认定为本机；其他地址读取操作系统当前网卡地址表
检查是否属于本机，不按私网网段推断。关闭时没有可信 peer 的请求被拒绝。
共享开启只放宽设备来源，原有 AI 调用密钥、管理密钥及管理远程访问限制仍有效。

`GET/PUT /v1/internal/gateway/console/lan-sharing` 使用管理鉴权和 no-store 响应，
请求与响应为 `{ "enabled": true }`。配置使用已有持久化写锁与原子替换，保存到
state 目录下 `console/lan-sharing.json`；保存失败不改变运行中的策略。
损坏配置不默认为开启：非本机请求拒绝，本机保留修复入口。

不会修改监听地址、端口、防火墙或系统网络设置。原本只监听 127.0.0.1 的实例，
即使开启共享也不会自动改为对外监听。这里的“其他设备”包括所有能够连接后端的
非本机来源，不仅限于某一私网网段。

反向代理部署按后端看到的代理连接来源判断；本机反向代理的访问视为本机。
如需限制代理背后的最终设备，必须同时在代理入口执行访问控制，不能信任任意转发头。
容器中本机地址以该进程所在网络命名空间为准。
