# Vercel AI Gateway

在服务商目录选择 **Vercel AI Gateway**，在账号内填写 AI Gateway API Key。
普通和流式聊天都固定走 Vercel 的官方地址。已有账号不需要重新录入 Key；
打开账号编辑，点击 **添加推荐的 Vercel 模型** 并保存即可增加模型及精确路由。

- **零价模型**：默认启用这一组。Gateway 核对官方目录的价格，不查赠额余额；
  零价不等于免费档有权限：推荐名单和网关模型列表都按档位资格筛选。
  团队限制或短时上游故障仍可能影响实际调用。
- **可用赠额抵扣的计费模型**：先在 Vercel 团队面板确认余额是月赠额，
  未购买额度、未启用自动充值或 BYOK，再把账号设为 **月赠额模式** 并添加推荐模型。
  同一把 Key 可使用两组模型。计费名单按官方 **Free Credit** 筛选资格和正价格核对，
  不把「可用赠额」视为「零价」。

旧配置无需迁移；下架型号即使仍保存在旧账号、路由或模型映射中，也不会通过
Vercel 出现在业务模型列表或被发送给 Vercel。其他服务商的同名型号不受影响。

正常计费请求直接发送，不查余额。只有上游返回可识别的余额耗尽 `402`，才暂停该
Key 的计费模型；自设预算错误 `quota_for_entity_exceeded` 不触发暂停，零价模型也不受影响。
暂停后有新的计费请求时，同一 Key 最多每小时复查一次；查到 `(0, $5]` 的普通余额后恢复，
不按自然月或固定等待时间盲目解禁，也不重放原失败请求。暂停状态只保留在当前进程，
重启后下一次计费请求重新由上游判定。

[余额 API](https://vercel.com/docs/ai-gateway/sdks-and-apis/rest-api#check-credit-balance)
不返回资金来源或普通赠额续期日期，所以月赠额模式依赖账号设置时的确认：
若后来购买额度、启用充值或 BYOK，请关闭本模式。余额回升不证明资金来自赠额，
此模式不提供跨应用或跨实例的硬性 $5 消费上限。
绑定付款方式与购买额度不是一回事；首次购买额度后，月赠额不再适用。
资格与定价以 [Vercel 定价](https://vercel.com/docs/ai-gateway/pricing) 和
[模型目录](https://vercel.com/ai-gateway/models?freeTier=true) 为准。
