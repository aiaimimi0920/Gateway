Create a generation
POST
/generations
Submit an image or video generation job. Returns immediately with an opaque job ID to poll via GET /generations/{id}.

Deletion deadline you set for this generation. It overrides your client's retention period for this generation, later or earlier: a successful generation is due for deletion at this deadline, a failed one at the earlier of this deadline and its failed-generation grace period, and one still running at the deadline as soon as it finishes. Once the deadline passes, GET /v1/generations/{generation_id} returns 404. Requires the managed retention add-on (
managed_retention
); silently ignored without it. A past value is rejected with 422; a value more than ten years ahead is clamped to ten years. See the Generation deletion guide.
