What is Luma MCP? 

A connector that lets LLMs use Luma inside the chat and return the finished image or video in Luma MCP connects Luma to AI assistants such as ChatGPT and Claude. Ask for an image, a video or a mini app run in the chat, and the finished result comes back in the same conversation.

Where can I use Luma MCP?

  • ChatGPT, through the official Luma plugin

  • Claude, through the Luma connector

  • And any agent / surface that can integrate with MCP

How do I connect Luma MCP?

ChatGPT

  1. Open Settings > Plugins and add Luma.

  2. Sign in with your Luma AI account in the browser window that opens.

  3. Start a new chat and ask, for example, "Use Luma to make an image of boots."

Claude

  1. Open Customize > Connectors and add Luma.

  2. Sign in with your Luma account in the browser window that opens.

  3. Start a new chat and ask Claude to use Luma.

Do I need an API key?

No. In ChatGPT and Claude you sign in with your Luma account. An API key is only needed if you connect Luma MCP to your own agent or app.

Where are my assets stored? 

Everything you generate or upload is stored in a Luma workspace, and it's still available after the chat ends. You can also save results to your team's Asset Library, which is shared across every chat.

Which Luma plans can use the MCP? 

 Available to all Luma App paid plans

Is the MCP the same as the Luma export/Claude Motion connector? 

No, they’re different.

  • Luma Export sends animations made in Claude Motion into Luma.

  • Luma MCP generates images and videos and runs mini apps from inside the chat.


What can I make besides images and videos?

You can run mini apps such as Background Swap, Camera Angles, Light Transfer and Face Swap, variants.

Does Luma AI MCP support SSE connections?

Connect over HTTP (Streamable HTTP) at https://agents.lumalabs.ai/mcp. 

How are my MCP generations billed?

MCP credits use Luma App’s credits from your regular subscription and work the same way as creating in Luma App.

If I am on an Enterprise plan, would my team's model restrictions and moderations apply?

Yes, model restrictions and moderations.

• A disabled model doesn’t show up in luma_model_list, so Claude/ChatGPT normally never tries it
• If it names one anyway (the user asks for it by name), the generate call fails with Unknown model: <id>. that’s expected: it’s the same error you get for a model that doesn’t exist.
