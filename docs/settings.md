# 设置面板

设置共用同一套管理控制台。桌面 EXE 显示五分类：界面偏好、后端连接、桌面行为、
管理安全、诊断与日志；普通浏览器只显示界面偏好、管理安全、诊断与日志。
分类可见性按访问端判断，不按 Gateway 的本地/远端地址判断，键盘导航只遍历可见项。
主题和语言使用单行 label＋下拉框，继续复用原本的本地偏好键。
五类内容使用通栏行：标签列与弹性控件列对齐，操作区靠右，细线分隔；不使用窄固定列，
也不为了填满底部空白而增加无用内容。地址输入与按钮在常规宽度同行，窄内容区才换行。
`gateway-ui-theme`、`gateway-ui-locale` 保存于当前浏览器/WebView 的 localStorage，
初始化读取；普通刷新/重开保留，按 origin 隔离，不作为服务端全局配置。
后端地址、测试连接、应用并连接同组同行；窄内容区允许换行，不撑宽整页。
复制成功仅换成勾＋「复制」，不改变按钮宽度。操作反馈保留固定高度。

## 后端连接与登录

「当前后端」与未应用的地址草稿分开。仅允许 HTTP(S) 根地址或 `/ui/`，
不接受 URL 用户名、密码、参数、fragment 或 `/v1`。配置中不保存管理密钥。
远端选择只保存规范化根地址，本机选择不保存未使用的远端地址草稿；编辑地址或
连接方式会清除旧的测试反馈，不把旧目标的测试成功显示为新目标的结果。

测试仅检查目标公开控制台，不修改连接配置、不启动或停止进程、不携带当前
管理密钥。普通浏览器不提供后端切换表单，访问其他 Gateway 时直接打开其 `/ui/`。

桌面应用先验证目标可访问，再保存选择并打开目标控制台，最后停止本客户端
原先管理的本机进程。目标检查失败时保留当前连接和运行中的本机后端。
已有后端模式不会静默回退成本机模式。应用连接不是自动登录：目标 Gateway
继续执行自己的管理登录流程，不接收旧后端的管理密钥。

## 原生权限边界

管理控制台由后端提供，其 WebView **仍然没有原生 IPC 权限**。
仅后端连接、桌面行为使用 `gateway-console` 原窗口内容区内的可信本地
子 WebView，不再弹出另一个设置窗口；原侧栏、顶部分类和管理登录会话保留。
本地表单从打包资产加载，禁止跳转到远端页面或打开弹窗。

展示桥只接受两个固定分类、有限几何尺寸、主题和语言；不传输后端地址、启动项、
路径、配置对象或凭证。设置消息通过资源请求发送，不修改宿主页面 location：
Windows 的 console 单独使用 HTTPS custom scheme，其他本地视图的 origin 不变。
原生端校验真实 WebView 标签、当前连接的精确 Origin、GET/空 body、URL 长度和白名单输入，
仅向已验证来源返回 CORS，不赋予远端 Tauri command 权限。

最多保留一个本地设置子视图，分类切换只更新上下文；离开本地分类时隐藏，完整文档导航、
切换后端时销毁。销毁是不能被普通几何请求覆盖的屏障。主题、语言同步及 React ready 后
才显示；ready/busy 带 revision，过期消息不能重新显示或锁定已隐藏内容。缩放和侧栏变化
仅更新区域，不重新挂载表单。前端请求最多一个 in-flight 和一个最新待处理项，原生端
最多一个 worker、一个最新待处理项和一个销毁屏障，均不产生无界队列。
打开后端设置只读取配置，不自动重连、启停服务或写入配置。

capability 只列出 `main` 和 `gateway-local-settings` 两个精确 WebView 标签，不授权
远端来源。`lib.rs` 保留服务端控制台的命令拒绝规则；子视图仅能调用设置相关白名单，
不能访问旧版 profile、进程控制和原始日志读取命令。连接失败在当前页显示错误；
独立 `main` 窗口只继续承担启动失败恢复和显式打开的独立连接入口。

普通浏览器和桌面控制台共用当前 Gateway 的管理密钥、日志策略和导出 API。
浏览器不能修改 Windows 启动项或关闭桌面程序，也没有原生文件系统权限。
桌面启动恢复窗口仅保留后端连接、桌面行为，不再提供另一套本机日志设置。

## 桌面行为

- 关闭窗口时：最小化到托盘、退出程序。托盘提供打开、设置、退出；`Ctrl+Q`
  始终退出，不随关闭按钮策略变成隐藏。真正退出时仍停止本客户端拥有的 sidecar。
- 开机启动：Windows 当前用户登录启动，使用专用的
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\NeuroGatewayDesktop` 值，
  无需管理员权限，不修改其他启动项。命令为带引号的 EXE 路径加
  `--gateway-autostart` 标记。新版安装路径可在下一次保存设置时更新已有标记项；
  不覆盖没有此标记的未知条目。
- 新的可选 `desktop-settings.json` 位于既有共享本地数据目录，不改变数据库版本、
  数据目录选择规则或凭证格式。写入使用临时文件与原子替换，读取有大小限制。
- 为兼容旧版，默认保留「关闭即退出」，开机启动取系统中的真实状态。
  托盘创建失败时不会接受「最小化到托盘」，避免隐藏后无法恢复。

## 管理安全

沿用真实管理密钥列表、管理员鉴权、最后一把密钥保护和二次删除确认。
替换或删除当前登录密钥后重新登录。明文仅按需请求，失焦、页面隐藏、会话变化、
离开该分类或 15 秒后移除，不落 localStorage。详见 `management-key-ring.md`。

## 诊断与日志

- 两端都操作**当前连接的 Gateway 后端机器**，不是运行 `gateway-ui` 的电脑。
- 后端初始化自己的文件 tracing writer，同时保留非受管实例的标准输出。默认日志目录
  为 console state 下的 `logs`；显式 `GATEWAY_CONSOLE_LOG_FILE` 选择实际日志文件。
  桌面 sidecar 将其启动捕获文件传给后端，避免重复写 tracing，保留早期 stdout/stderr。
- 页面显示后端日志目录，提供固定宽度「勾＋复制」，不打开客户端本机文件夹。
- 诊断和日志分别导出 JSON、脱敏 `.log` 到当前访问端；切换后端或退出页面会取消请求，
  丢弃旧请求结果，不下载上一个后端的响应。
- 日志保留时间：不自动清理、3 天、7 天、30 天。
- 历史日志上限：不限、100 MB、200 MB、500 MB。按较早时间优先清理。
- 默认不自动清理，也不限制历史容量，避免升级时删除已有记录。
- 策略保存到后端 console state 的 `log-policy.json`，在**该 Gateway 下次启动时**执行；
  只处理 `gateway-runtime-*.log` 和受保护的 `gateway-v2-*.log`。
  旧版日志及非 Gateway 文件保留；正在写入的日志不截断、不计入历史限额。
  Windows 写入者禁止删除共享，清理者持有排斥写入者的文件 lease；Unix 使用文件锁。
  拒绝重定向目录/文件，不递归遍历，并限制单次扫描数量。
- 诊断只导出后端版本、系统/架构、PID、运行/存储模式、日志目录和策略等白名单信息。
  不序列化 Config、环境变量、路由文档、凭证、数据库或管理密钥；目录路径是管理员
  明确可见的信息，不宣称诊断报告已匿名化机器路径。
- 日志导出最多扫描 4096 个目录项，选最近 16 个日志，每文件最多 256 KiB。
  超限返回 `truncated=true`，文件和页面都明确标记。丢弃截断尾部的首条不完整记录，
  所有命中的授权头、token/key/password、URL userinfo 等按每次出现脱敏；磁盘原日志不改写。
- 文件读取拒绝非普通文件、静态符号链接/reparse point、硬链接，读取有动态字节上限。
  不接受请求路径；日志目录须由可信的操作系统账户管理，不声称可抵抗具有同目录写入
  权限的本机恶意进程在所有路径检查间隙替换父目录。
- API：`GET/PUT /v1/internal/gateway/console/diagnostics/settings`，
  `POST /v1/internal/gateway/console/diagnostics/export`，请求 `{ "kind": "diagnostics" | "logs" }`。
  均使用既有管理令牌、remote-access 边界和 `Cache-Control: no-store`，无新鉴权旁路。
- 旧 `desktop-settings.json` 的日志字段仍兼容读取和原样保存，但不再由诊断与日志面板修改，
  也不再驱动日志清理。
  不迁移/删除既有日志，不改数据目录、数据库版本或凭证。

历史日志上限不是运行中日志的硬容量限制；本次没有引入 stdout 在线轮转。
不会为设置而自动重启当前后端；远端策略修改仅通过目标 Gateway 的管理员 API 完成。
